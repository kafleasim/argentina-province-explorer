# Argentina province explorer

Interactive, single-file report on learning outcomes, the teaching workforce, teaching posts and pay across Argentina's 24 provinces, with ERCE, PISA and MICS benchmarks. Built as the evidence base for an API-209 / DEV-401 final exercise (HKS, Fall 2026) on a model teacher statute.

**Open it:** https://kafleasim.github.io/argentina-province-explorer/

Sources: Aprender 2016–2025 (Ministerio de Educación), Relevamiento Anual 2011–2025, CGECSE teacher salaries, ERCE 2019 (UNESCO LLECE), PISA 2000–2018 (OECD), MICS 2019–20 (UNICEF/INDEC). The page contains only province- and national-level aggregates computed from these public sources; no microdata. Descriptive evidence only.

The file is generated by a Stata/R/Python pipeline kept outside this repo; to update, rebuild `province_report.html` and copy it here as `index.html`.
