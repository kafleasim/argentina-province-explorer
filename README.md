# Argentina province explorer

Interactive explorer and report on learning outcomes, the teaching workforce, teaching posts and pay across Argentina's 24 provinces, with ERCE, PISA and MICS benchmarks, and the group's coding of the 24 provincial teacher statutes (22 rules as edited by the group on 17 Nov 2026, model-statute indices) shown next to each outcome with a plain-language read-out of how much of the differences between provinces each statute measure, or a chosen set of measures, explains. Numeric statute rules enter as "has the rule" plus the amount above a cut, and uncoded provinces as their own category (switchable). Also: side-by-side comparison of up to 8 provinces, play-over-time buttons, a source line and a higher/lower-is-better tag on every figure, and a separate teacher-pay tab. Built as the evidence base for an API-209 / DEV-401 final exercise (HKS, Fall 2026) on a model teacher statute.

**Open it:** https://kafleasim.github.io/argentina-province-explorer/

Sources: provincial teacher statutes as coded by the project group; Aprender 2016–2025 (Ministerio de Educación), Relevamiento Anual 2011–2025, CGECSE teacher salaries, ERCE 2019 (UNESCO LLECE), PISA 2000–2018 (OECD), MICS 2019–20 (UNICEF/INDEC). Apart from the ERCE regression lab, the page contains only province- and national-level aggregates computed from these public sources. The ERCE regression lab embeds the de-identified ERCE 2019 public-use pupil file for Argentina (UNESCO-LLECE; 10,073 grade-3 and grade-6 pupils, questionnaire answers and plausible values, no names or school identities) so that regressions run in the browser; the page is therefore about 7 MB. Descriptive evidence only: statute–outcome links are cross-province associations (at most 24 provinces), not effects.

Pages (use the menu at the top left):

- `index.html`: province explorer
- `report/index.html`: report, diagnostic tree and what the data say about each branch
- `report/analysis.html`: report, regressions and findings (corrected 22 Nov 2026 and updated to the 17 Nov statute coding; one coding question is still open, see the note on that page)

The files are generated by a Stata/R/Python pipeline kept outside this repo. To update, rebuild `province_report.html` and the report, then run `09_build_site.py` from the project sandbox. Do not copy `province_report.html` here directly: that removes the menu.
